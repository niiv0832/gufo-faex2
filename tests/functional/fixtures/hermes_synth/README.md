# Синтетический набор запросов Hermes Agent

Назначение: одинаковые входы для сравнения режимов спекуляции (`off`, MTP1, DFlash2, `auto`) по [проекту проверки](../../../../docs/faex2/DFLASH2_EVAL_PLAN_2026-11-15.md). Это не приёмочный набор и не оценка качества.

## Происхождение

- Hermes Agent v0.22.2, коммит `cc6b1f299bd3` (`NousResearch/hermes-agent`, лицензия MIT — [LICENSE.hermes-agent](LICENSE.hermes-agent)).
- Запись сделана 2026-11-15: `hermes -z` в чистом временном `HERMES_HOME` (без памяти, навыков пользователя, ключей и расписаний) против локальной заглушки, которая отвечает только текстом. Модель и стенд не участвовали.
- `base_request.json` — системный промпт, 20 описаний инструментов и параметры запроса как их отправил Hermes; пути машины заменены на `/home/user/...`.
- `aux_title_request.json` — служебный запрос названия сессии со строгой JSON-схемой (`response_format`).
- `cases.jsonl` — 15 написанных вручную префиксов диалога: `tool` (ожидается вызов инструмента), `mixed` (после результата нужен следующий вызов), `prose` (русский ответ). Результаты инструментов выдуманы и зашиты в префикс; инструменты не исполняются.

## Границы

- Чистый профиль короче настоящего: нет пользовательских навыков и памяти в промпте.
- Hermes отправляет `reasoning_effort: medium`, поэтому в ответах будет и рассуждение, и вызов; классы описывают ожидаемый итог хода, а не чистый состав токенов.
- Положительный вывод по этому набору — предварительный до повторения на записанных реальных сессиях.

## Использование

```sh
python3 tests/functional/hermes_synth.py                 # перечень случаев
python3 tests/functional/hermes_synth.py --dump tool-01-search
python3 -m unittest discover -s tests/functional -p test_hermes_synth.py
```

Файлы закреплены по SHA-256 в `hermes_synth.py`; изменение набора после начала измерений делает результаты несопоставимыми.
